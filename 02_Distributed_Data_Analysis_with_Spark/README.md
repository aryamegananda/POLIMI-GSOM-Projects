# Distributed Data Analysis with Apache Spark  
Group Project

🚧 **Status: Ongoing project**

This project is a **group-based academic assignment** developed as part of the Master’s program in Business Analytics & Data Science.  
It focuses on applying **Apache Spark** to perform scalable data processing and analytical queries on structured datasets.

The objective of the project is to demonstrate familiarity with Spark’s distributed computation model, including aggregation, grouping, ranking, and query design.

---

## Project Overview

This project explores **sales performance, customer behavior, and logistics patterns** using the **Superstore dataset**, analyzed through **Apache Spark DataFrames**.

The goal is to apply distributed data processing techniques to perform large-scale analytical queries, including:
- sales and revenue aggregation,
- customer and product-level analysis,
- regional and categorical performance comparison,
- and logistics-related insights such as shipping behavior.

---

## Project Context

The project was developed within the context of a mandatory course on **Big Data and Distributed Data Processing**.  
The emphasis is on:
- correct use of Spark APIs,
- scalable query logic,
- and clear analytical reasoning over large datasets.
