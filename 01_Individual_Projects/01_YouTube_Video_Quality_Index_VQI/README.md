# Video Quality Index (VQI): A Behavioral Measurement Study

🚧 **Status:** Ongoing project

## Overview
This project explores how observable viewer behavior can be used to construct a measurement index for video quality in the absence of explicit labels or ground truth.  
The outcome is a Video Quality Index (VQI), a composite and interpretable score at the video level, with emphasis on robustness, validation, and clearly stated assumptions.

### This project involves:
- Data mining
- Preprocessing of behavioral signals  
- Problem framing and measurement design  
- Feature and signal selection  
- Index construction and validation  
- Model and specification comparison (where applicable)
